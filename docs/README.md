## 🎓 Learning Paths

### Path 1: Beginner (Recommended)
Perfect if you're new to DocumentDB or FastAPI.

1. Read [LAB_SETUP_COMPLETE.md](LAB_SETUP_COMPLETE.md) (5 min)
2. Run `.\scripts\setup-lab.ps1` (5 min)
3. Follow [LAB_WALKTHROUGH.md](LAB_WALKTHROUGH.md) (30-45 min)
4. Keep [CHEAT_SHEET.md](CHEAT_SHEET.md) open for reference
5. Try queries in `../examples/ecommerce-analytics.mongodb`

**Total Time**: ~1 hour

---

### Path 2: Intermediate (Hands-On)
You know Docker and APIs, want to dive right in.

1. Skim [LAB_SETUP_COMPLETE.md](LAB_SETUP_COMPLETE.md) (2 min)
2. Run `docker-compose up --build` (5 min)
3. Jump to [LAB_WALKTHROUGH.md - Step 2](LAB_WALKTHROUGH.md#step-2-load-e-commerce-data-using-vs-code-extension)
4. Use [EXTENSION_QUICK_REFERENCE.md](EXTENSION_QUICK_REFERENCE.md) as needed
5. Review [ARCHITECTURE.md](ARCHITECTURE.md) to understand internals

**Total Time**: ~30 min

---

### Path 3: Advanced (Deep Dive)
You want to understand everything before starting.

1. Read [ARCHITECTURE.md](ARCHITECTURE.md) (15 min)
2. Read [DOCUMENTDB_EXTENSION_GUIDE.md](DOCUMENTDB_EXTENSION_GUIDE.md) (20 min)
3. Review [../scripts/README.md](../scripts/README.md) (10 min)
4. Follow [LAB_WALKTHROUGH.md](LAB_WALKTHROUGH.md) selectively
5. Experiment with `../examples/ecommerce-analytics.mongodb`

**Total Time**: ~1.5 hours
